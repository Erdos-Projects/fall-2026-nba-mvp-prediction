# fall-2026-nba-mvp-prediction
Team project: fall-2026-nba-mvp-prediction

## Setup
1. Create and activate your project conda env
2. Install the packages: `conda install -c conda-forge --file requirements.txt`

Upon cloning the directory the first thing that need to be done is to download the data.  This takes about 8 minutes and is achieved by uncommenting and running the cell eith `utils.scrape_per_game_tables(START_YEAR,END_YEAR)` in `data_collection/player_eda.ipynb`.
